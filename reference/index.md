(1978-present)

- [`get_business_dynamics_by_sector()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_business_dynamics_by_sector.html)

- [`get_business_dynamics_by_age()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_business_dynamics_by_age.html)
  : Get Business Dynamics Data by Establishment Age (from cori.data.bds)
- [`get_business_dynamics_by_size()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_business_dynamics_by_size.html)
  : Get Business Dynamics Data by Firm Size (from cori.data.bds)
- [`get_employment_dynamics()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_employment_dynamics.html)
  : Get Employment Dynamics Data (from cori.data.bds)
- [`get_employment_dynamics_by_sector()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_employment_dynamics_by_sector.html)
  : Get Employment Dynamics Data by Sector (from cori.data.bds)
- [`get_employment_dynamics_by_age()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_employment_dynamics_by_age.html)
  : Get Employment Dynamics Data by Establishment Age (from
  cori.data.bds)
- [`get_employment_dynamics_by_size()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_employment_dynamics_by_size.html)
  : Get Employment Dynamics Data by Firm Size (from cori.data.bds)
- [`get_bds_codebook()`](https://ruralinnovation.github.io/cori.data.bds/reference/get_bds_codebook.html)
  : Get BDS Variable Codebook (from cori.data.bds)
- [`pull_bds_raw()`](https://ruralinnovation.github.io/cori.data.bds/reference/pull_bds_raw.html)
  : Pull raw BDS data using the Census API (from cori.data.bds)

## S3 Data Access

Low-level S3 operations for reading/writing data

- [`connect_to_s3()`](https://rdrr.io/pkg/cori.data.s3/man/connect_to_s3.html)
  : Open a DuckDB connection configured for S3 access (from
  cori.data.s3)
- [`has_local_aws_credentials()`](https://rdrr.io/pkg/cori.data.s3/man/has_local_aws_credentials.html)
  : Detect locally configured AWS credentials (from cori.data.s3)
- [`set_aws_credentials()`](https://rdrr.io/pkg/cori.data.s3/man/set_aws_credentials.html)
  : Install aws credentials in your .Renviron file and load credentials
  into the current environment. This actions will overwrite any values
  currently stored in AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY. (from
  cori.data.s3)
- [`get_s3_object()`](https://rdrr.io/pkg/cori.data.s3/man/get_s3_object.html)
  : Download an object that is hosted on S3 (from cori.data.s3)
- [`read_s3_object()`](https://rdrr.io/pkg/cori.data.s3/man/read_s3_object.html)
  : read a text file (csv) in a s3 object in memory (from cori.data.s3)
- [`write_s3_object()`](https://rdrr.io/pkg/cori.data.s3/man/write_s3_object.html)
  : write a data.frame into a csv in a s3 bucket (from cori.data.s3)
- [`list_s3_objects()`](https://rdrr.io/pkg/cori.data.s3/man/list_s3_objects.html)
  : List every "keys" from a bucket (from cori.data.s3)
- [`sync_s3_to_local()`](https://rdrr.io/pkg/cori.data.s3/man/sync_s3_to_local.html)
  : Sync S3 objects to a local directory (from cori.data.s3)
